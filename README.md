# Slack Chat — аналог Slack

[**Демо приложения**](https://frontend-project-12-1-ru98.onrender.com)

## Описание проекта

Slack Chat — это веб-приложение для обмена сообщениями, разработанное по аналогии с популярным мессенджером Slack. Приложение позволяет пользователям общаться в режиме реального времени, создавать и управлять каналами, а также обмениваться сообщениями в удобном интерфейсе.

## Возможности

- **Регистрация и авторизация** — создание аккаунта и вход в приложение.
- **Обмен сообщениями в реальном времени** — отправка и получение сообщений без необходимости обновлять страницу.
- **Управление каналами** — создание, переименование и удаление каналов.
- **Фильтрация ненормативной лексики** — автоматическая обработка сообщений с использованием фильтра ненормативной лексики.

## Технологии

React, Tailwind CSS, Vite, Redux Toolkit, WebSocket

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/DamirLyapin/frontend-project-12.git
cd frontend-project-12
```

### 2. Установка зависимостей

```bash
make install
```

### 3. Запуск приложения

```bash
make start
```

После запуска приложение будет доступно по адресу, указанному в терминале.
